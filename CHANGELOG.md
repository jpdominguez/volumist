# Changelog

## 1.3.0

- A welcome screen on first launch, which explains the audio permission and the main options.
- A What's New screen after each update, also available from the Volumist window.

## 1.2.1

- Fixed the window sometimes reopening when closing it from the menu bar icon.

## 1.2.0

- Automatic leveling for each app, to even out loud and quiet parts.
- 10-band equalizer for each app, with presets.
- Left/right balance for each app.
- Level meters, active only while the Volumist window is open.
- System volume slider.
- Optional update check, off by default.
- The window now stays anchored to the menu bar and the app list scrolls when it doesn't fit.
- Apps are always listed alphabetically.
- Reset a single app from its details, close the window with Escape or by clicking elsewhere.
- System sounds are listed as System Sounds.
- Fixed muting having no effect the first time on an app with default settings.

## 1.1.0

- Lower other apps automatically during calls, with a configurable level.
- Choose whether any app using the microphone counts as a call, or only known call apps.
- Exclude individual apps from being lowered.

## 1.0.0

First public release.

- Per-app volume from 0% to 150%, with a soft limiter above 100%.
- Per-app mute.
- Per-app output routing, with automatic fallback when a device disconnects.
- Settings remembered for each app.
- Helper processes grouped under their parent app.
- Open at login.
